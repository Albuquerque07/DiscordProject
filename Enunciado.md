Cada grupo, em seu próprio tema, irá implantar o seu banco de dados no SGBD do laboratório (fase III) e elaborar interface CRUD em python (ou outro recurso de domínio do grupo, pois o foco não é a interface).

A apresentação será através de casos de uso imaginários através das telas (console), feito tanto por um usuário típico do caso de uso.

O grupo precisa escolher um ponto crítico de uso do portal para criar um índice, explicar e comprovar a melhoria de performance através da comparação de plano de execução.

O Professor poderá requisitar uma leitura específica do seu banco de dados ao final da apresentação. Essa leitura consiste na elaboração de uma instrução SQL (SELECT).

Material esperado para entrega:

Todos os códigos utilizados, tanto de criação quanto de manipulação de dados.

Instrução SQL do índice criado para melhorar um ponto crítico de uso do sistema.
